📜 Règlement du Challenge KG Evaluator

Contexte : Ce challenge évalue la capacité des systèmes à annoter sémantiquement des données tabulaires.

Les Tâches

  • CEA (Cell Entity Annotation) : Associer une cellule à une entité du KG.
    Format : tab_id, row_id, col_id, entity_url
  • CTA (Column Type Annotation) : Associer une colonne à une classe du KG.
    Format : tab_id, col_id, class_url
  • CPA (Column Property Annotation) : Identifier la relation entre deux colonnes.
    Format : tab_id, col1_id, col2_id, property_url
  • RA (Row Annotation) : Associer une ligne entière à une entité.
    Format : tab_id, row_id, entity_url

Évaluation

Le système calcule automatiquement la Précision, le Rappel et le Score F1.
Le classement final est basé sur le Score F1.
